# 🚦 Road Accident Analysis Dashboard

An interactive **Power BI dashboard** designed to analyze road accident data and uncover meaningful patterns related to accident severity, casualties, locations, vehicle types, and time-based trends.

The dashboard transforms raw accident data into clear visual insights, helping users understand **where, when, and how road accidents occur** and identify major factors contributing to casualties.

## 📊 Key Insights

* 🚗 Total accidents and casualties overview
* 📍 Accident analysis by location
* 🕐 Accident trends by time and date
* 🚘 Analysis by vehicle type
* ⚠️ Accident severity distribution
* 🛣️ Road and road-surface condition analysis
* 🌦️ Weather-condition analysis
* 📈 Monthly and yearly accident trends
* 🔎 Interactive filters and slicers

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Cleaning & Transformation**
* **Data Visualization**

## 🎯 Dashboard Objective

The primary goal of this project is to convert accident records into actionable insights through interactive visualizations, making it easier to identify accident patterns, high-risk conditions, and casualty trends.

## 📈 Outcome

This dashboard provides a consolidated view of road accident statistics and enables users to explore the data dynamically using filters, charts, KPIs, and interactive visuals.
