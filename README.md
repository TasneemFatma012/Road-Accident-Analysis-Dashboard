# 🚦 Road Accident Analysis Dashboard

An interactive **Power BI Dashboard** developed to analyze road accident data and identify meaningful insights related to accident severity, casualties, vehicle types, road conditions, weather, and time-based trends.

This project transforms raw accident data into interactive visualizations to help understand accident patterns and explore factors associated with road accidents.

## 📌 Project Overview

The Road Accident Analysis Dashboard provides a comprehensive view of road accident statistics through interactive charts, KPIs, and filters.

It helps users explore accident trends, compare casualty figures, and analyze how different conditions relate to road accidents.

## 🎯 Project Objectives

- Analyze total road accidents and casualties.
- Understand accident severity and casualty distribution.
- Identify accident trends across different months and years.
- Analyze accidents based on vehicle types.
- Explore the impact of road types and road-surface conditions.
- Examine accident patterns under different weather conditions.
- Present insights through an interactive Power BI dashboard.
